# PROJECT DOCUMENTATION

**Project Name:** Alpine Ascents

**My Part:** Explore Section and Success Stories Section

### What I Did
I worked on two sections of the Alpine Ascents website: the Explore section and the Success Stories section.

The Explore section displays nine different mountains around the world, including their names, locations, heights, difficulty levels, climbing seasons, descriptions, and images.

The Success Stories section displays nine important mountaineering achievements, including the names of famous climbers, their achievements, the years they happened, and short descriptions.

### How I Did It
I used **React.js, JavaScript (JSX), and CSS** to build both sections.

- I created `ExploreSection.jsx` to display the mountain destinations.
- I created `SuccessStoriesSection.jsx` to display the mountaineering stories.
- I used JavaScript arrays to store the information and the `.map()` method to display the cards.
- I used CSS to design the cards, add images, create rounded corners, arrange the cards in three columns, and add hover effects.
- I created `MountainSections.css` to handle the styling of both sections.
- I connected both sections to the main website using React Router.

**Routes:**
- `/explore`
- `/success-stories`

### What I Learned
I learned how to create React components, use arrays and the `.map()` method, style webpages with CSS, and connect different sections of a website using React Router.
