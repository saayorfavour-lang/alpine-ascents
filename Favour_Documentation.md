# ALPINE ASCENTS
## Project Documentation – Favour's Contribution

### 1. Project Overview

Alpine Ascents is a mountaineering information website designed to educate visitors about mountain exploration, mountaineering history, mountain hazards, safety practices and notable climbing experiences.

The website provides an accessible and informative platform for people interested in learning about mountaineering.

### 2. Technologies Used

- React.js – Building reusable user interface components.
- Vite – Frontend development and build tool.
- JavaScript – Website functionality and interactivity.
- CSS3 – Styling, layouts and responsive design.
- React Router DOM – Navigation between website pages.
- Git and GitHub – Version control and team collaboration.

### 3. My Responsibilities

My assigned responsibilities as a team member and team lead include:

- Homepage development.
- Header and navigation development.
- Learn section and learning topic navigation.
- Visitor counter integration.
- Scrolling information ticker.

### 4. Homepage Development

The homepage serves as the main entry point of the website.

It includes:
- An introductory hero section.
- Mountaineering-themed background imagery.
- A short introduction to the website.
- Navigation buttons directing visitors to other sections.
- Consistent Alpine Ascents branding.

### 5. Header and Navigation

The header provides navigation throughout the website.

It includes:
- Alpine Ascents branding and logo.
- Home navigation.
- Learn dropdown menu.
- Explore navigation.
- Success Stories navigation.
- Latest navigation.
- Contact navigation.
- Visitor counter.
- Plan Your Climb call-to-action.

The header is designed to maintain a consistent navigation experience across the website.

### 6. Learn Section

The Learn section provides educational information about mountaineering.

The six learning categories include:

1. History of Mountaineering
2. Mountain Hazards
3. Mountain Safety
4. Sheltering
5. Types of Mountains
6. Safety Guidelines

Each category provides access to its corresponding learning content.

### 7. Visitor Counter

The visitor counter displays the number of recorded website visits.

It helps visitors and the project team see the website's recorded visit count.

### 8. Scrolling Information Ticker

The scrolling ticker displays useful information, including:
- Current date.
- Current time.
- Location information.

It adds a dynamic information element to the website.

### 9. Design and User Experience

The visual identity of Alpine Ascents uses a nature-inspired colour palette:

| Colour | Hex Code | Usage |
|---|---|---|
| Alpine Green | #183C32 | Header, headings and buttons |
| Antique Gold | #C6A15B | Accents and highlights |
| Warm Ivory | #F4F0E6 | Backgrounds and text accents |

The design focuses on readability, clear navigation, visual consistency and responsiveness across different screen sizes.
